# klipper-ui

Custom UI/UX for a Klipper printer: a **Mainsail** theme/layout plus a **KlipperScreen** theme/menus on a BTT TFT35 SPI, with matching macros.

Hardware: BTT Pi, BTT TFT35 SPI, Mellow FLY Micro4, cantilevered bed-slinger, E3D PZ probe.
